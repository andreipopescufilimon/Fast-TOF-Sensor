# HLR ToF Module V1.0

The HLR ToF Module V1.0 is a compact distance sensing board based on the **VL53L5CXV0GC/1** multi-zone Time-of-Flight sensor, designed for robotics and embedded systems.

<img width="558" height="473" alt="Screenshot 2026-09-06 122913" src="https://github.com/user-attachments/assets/a65a9c75-6c0b-4b3a-b9c1-02c7858f6b4c" />

It can measure distance across an 8 × 8 grid with up to 64 sensing zones, allowing a robot to detect both the distance and approximate position of nearby objects.

Main Features:
- VL53L5CXV0GC/1 ToF sensor
- Up to 64 ranging zones
- Up to approximately 4 m measurement range
- Wide field of view
- I²C communication
- 4 × 4: up to 60 readings/s, approximately 16.7 ms between readings
- 8 × 8: up to 15 readings/s, approximately 66.7 ms between readings
- Compact custom PCB
